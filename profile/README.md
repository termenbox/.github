# Termenbox

Termenbox is a self-hosted web terminal for AI coding agents such as Claude Code and Codex. You install it on your own server, open it in a browser on your phone or laptop, and your workspaces keep running in tmux and survive dropped connections. There is no app to install and no subscription.

- Product repository: [termenbox/termenbox](https://github.com/termenbox/termenbox)
- Install, on the Linux machine that will run your agents:

  ```bash
  curl -fsSL https://app.termenbox.dev/i | sh
  ```

- Support: ask in [GitHub Discussions](https://github.com/termenbox/termenbox/discussions) of the product repository. See [SUPPORT.md](../SUPPORT.md) for what a good question contains.
